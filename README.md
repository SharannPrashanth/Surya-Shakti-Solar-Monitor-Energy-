# Surya-Shakti Solar Monitor

## Overview
Surya-Shakti Solar Monitor is an Android application developed to help solar-enabled households monitor daily solar generation, electricity consumption, and energy savings.

## Features
- Daily solar generation logging
- Electricity consumption tracking
- Green Energy Independence Score
- Savings calculation
- Peak sunlight usage suggestions
- Over-generation analysis
- 30-day savings report

## Technologies Used
- Kotlin
- Android Studio
- Room Database
- XML
- RecyclerView
- SQLite

## Objectives
- Promote renewable energy adoption
- Help users optimize electricity usage
- Reduce dependency on traditional power grids

## Future Enhancements
- Real-time IoT integration
- AI-based energy prediction
- Weather API support
